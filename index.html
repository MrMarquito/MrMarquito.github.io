How FTP downloads a file

FTP uses one connection to ask for a file and another to send it. Try a sample transfer. No server is contacted and nothing is saved to your device.

  1. Open the connection used to send commands.
  3. Receive the file over a separate connection.

Protocol details

The command connection usually starts on port 21. Before asking for a file, the client sends PASV to find out where to open the separate file connection.

Example: the server replies 227 Entering Passive Mode (198,51,100,24,195,80). The client combines the last two numbers to get the file connection’s port: 195 × 256 + 80 = 50000.

The client opens that connection and sends RETR notes.txt on the command connection. The server sends the file over the new connection and then closes it.
